## 🧙‍♂️ Scroll #587: Zip the Application with Image (Windows 8.1 Compatible)

Here’s a Python script that will:

- Zip your entire application folder (e.g. `lunara-sentinel`)
- Include an image (e.g. `logo.png`, `banner.jpg`, etc.)
- Produce a single `.zip` file you can run or share

### 📦 `zip_lunara.py`
```python
import zipfile
import os

# Configuration
project_folder = "G:/Projects/lunara-sentinel"
output_zip = "LunaraSentinelBundle.zip"
image_file = "G:/Projects/lunara-sentinel/assets/logo.png"  # Change if needed

# Create zip
with zipfile.ZipFile(output_zip, 'w', zipfile.ZIP_DEFLATED) as zipf:
    # Walk through project folder
    for root, dirs, files in os.walk(project_folder):
        for file in files:
            filepath = os.path.join(root, file)
            arcname = os.path.relpath(filepath, project_folder)
            zipf.write(filepath, arcname)

    # Add image separately
    if os.path.exists(image_file):
        zipf.write(image_file, os.path.basename(image_file))

print(f"✅ Zipped to {output_zip}")
```

---

## 🧪 How to Run on Windows 8.1

1. Open Command Prompt or PowerShell
2. Activate your Python environment
3. Run:
   ```bash
   python zip_lunara.py
   ```
4. You’ll get `LunaraSentinelBundle.zip` in your working directory
